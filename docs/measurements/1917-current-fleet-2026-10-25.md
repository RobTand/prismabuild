### Probe budget beside the observed operation mix

The measured deployed plugin samples about once per second. Each successful
sample requests **five stat calls, five read-only open/close pairs, five listdir
calls, and five claim cycles**. Each old claim cycle creates, writes six bytes,
closes, renames and unlinks. Setup creates the directory and anchor once.
Thus one steady-state sample requests five RENAME, five REMOVE and five small
WRITE operations, plus the read-side loops. These are syscall budgets. Attribute,
dentry, data and open-state caches, NFS compounds and recovery prevent a fixed
one-syscall-to-one-RPC conversion.

The same retained `readonly-<host>-initial.json` windows used in the table above
give this selected-mount operation mix. Rates use their actual monotonic intervals,
30.0462 seconds on sparky and 30.0480 seconds on sparklina.

### Verification and remaining acceptance

The rerunnable reducer is
[`nfs_metadata_attribution.py`](../../tools/maintenance/nfs_metadata_attribution.py).
It reuses `mount_latency.read_mountstats`, joins unfinished/resumed strace calls,
keeps both entry and completion times, separates failed calls, and follows
observed fork/clone lineage. Both timestamps must lie within the selected
`[start, end)` window. A local
pathname does not become an NFS operation merely because `AT_FDCWD` points into
`/mnt/shared`. The admitted fixture checks that case, child attribution,
resumed calls, failed NFS calls and a lookalike `/mnt/shared-old` prefix.

PB action `8e732643f7c6cd74000157b293642b326cded7067d911544bc1c06a25ea2a16a`
ran the fixture and reduced both full paired traces on dl380g10: `executed`, rc 0.
It reserved one CPU, 1 GiB, no GPU, and one native thread per library, with a
180-second execution bound. The terminal record, complete stdout hash and CAS
payload were read back. `pb_verify_claim(hash_payload=true)` returned
`checks_passed=true`, `complete=true`, with no unavailable or timed-out section.
This verifies the analysis artifact, not per-process NFS attribution or worker
attestation. The evidence record names the sealed source and all input digests.

Remaining acceptance is explicit:

- Exact RPC shares per process are unknown. The GETATTR burst has a named
  recurring syscall producer, but the RPC total is still client-wide.
- A numeric unexplained-RPC residual cannot be derived by subtracting syscall
  rates. Its size relative to the 5% threshold remains unknown. The threshold
  is 4.729 ops/s and 5.024 ops/s for these two paired windows.
