Raw reports are the CAS payload bytes, copied without modification:
[sparky](gate_1730_sparky_2026-10-25.json) and
[sparklina](gate_1730_sparklina_2026-10-25.json).
`space` names the candidate destination `/home/rob/models-local` and records
unprivileged `f_bavail * f_frsize`. These observations reserve no capacity.

| Host | Available bytes | Filesystem bytes | D1 fresh-copy fit |
|---|---:|---:|---|
| sparky | 420041191424 | 1968362958848 | fits |
| sparklina | 265303769088 | 982819848192 | fails copy allowance |

The retained historical A8S size is `N = 175527382717` bytes. It is an input to
this preflight, not a new recursive size or integrity measurement. D1 requires
`available >= 1.5*N + 20*2**30 = 284765910555.5` bytes, and
`available - N >= 0.05*filesystem_bytes`. Sparklina passes the latter inequality
but falls short of the copy inequality by `19462141467.5` bytes, about 18.13 GiB.
No cleanup, second A8S copy, or host-policy change was performed.

These are fresh-copy inequalities. Same-filesystem adoption of existing bytes
has different space costs. This shortfall alone does not prove adoption is
impossible. Adoption remains unqualified and was not attempted.

Both reports' `stage_path.present` is false for the documented staged A8S root.
Their closest-ancestor mount records show that `/stage/prewarm` itself is
mounted over NFS-RDMA. An absent A8S subdirectory does not prove that every
possible alternate staged copy is absent; this probe searches only the declared
root and does not scan the tier or queue for substitutes.

Sparky's `canonical_path.mountinfo` resolves to a read-only ext4 bind from
`/home/rob/models-local/a8s-exported`. Reading it as an HDD arm would be false
attribution. Sparklina's corresponding path resolves to the `/mnt/shared`
NFS-RDMA mount. The two canonical paths therefore cannot be assumed to serve
the same physical tier. No model payload was opened to establish these facts.

Docker reports server version 29.6.2 on both hosts. Each fixture forces
`--entrypoint /bin/sh`, disables networking, prohibits pulling, and names an
installed immutable image ID. It runs shell file operations, not vLLM.

| Host | Local image ID |

| sparklina | `sha256:acc684c06ec79aa303deda50a15c422084690d3252d2449e9702b40de571fe63` |

The images differ. These are independent correctness fixtures, not timing arms.
Each raw `bind.calls` array records the complete arguments and output:

- The baseline lists the synthetic canonical marker.
- The nested read-only bind lists only the two local markers and reads
  `local-wins`, with exit 0. It shadows the whole synthetic canonical directory.
- Writing the existing local marker through that bind exits nonzero with
  `Read-only file system`. The host then reads the unchanged `local-wins` marker.
- A nonexistent bind source exits 125 with `bind source path does not exist`.

All three explicit result predicates are true on both hosts. These fixture
results establish Docker mount behavior. They establish no resident-set lease,
production pin lifetime, real A8S identity, or ID-07 reader-open attribution.
